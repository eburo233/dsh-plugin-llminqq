# 记忆总表

> 每个对端（群 / 私聊）一份见闻录，文件名叫 `memory/<类型>-<号>.md`。
> 这是我自己维护的，不是桥自动写的。想不起某件事的时候翻这里。
> 只记有用的：谁常说什么、最近在聊什么、答应过谁什么、什么话题别再提。

## 结构

```
memory/
├── memctl.py        # 记录/检索/衰减脚本（我写的，可改）
├── mem.db           # 长期层：条目 + 强度 + 半衰期
├── digest.md        # 自动生成的摘要，每轮可以直接读这个
├── log/             # 短期层：原文流水，按天切
├── README.md        # 本文件
└── *.md             # 手写的见闻录（人设性质的东西放这）
```

## 双层 + 半衰期

- 短期层 `log/<peer>-<日期>.jsonl`：逐条原文，留着回溯上下文。
- 长期层 `mem.db`：每条一个强度，按 0.5^(天数/半衰期) 衰减。
- 半衰期：强记忆点 180 天、人物 60 天、待办 30 天、普通事实 14 天、话题 3 天。
- 强度低于 0.15 的归档（不删，标记 retired），防止无限膨胀。

## 强记忆点的判定

同时满足两条才钉住：
1. 出现「记住 / 以后 / 每次 / 必须 / 不要 / 一律 / 只对」这类词；
2. 出现「以后 / 每次 / 一律 / 默认 / 长期 / 说好了」这类长期意味。

只说一次「不要回这句」不会变成永久规则，避免把临时情绪钉死。

## 怎么用

```bash
python3 memory/memctl.py ingest                     # 从 bridge 日志增量抓
python3 memory/memctl.py digest                     # 重生成 digest.md
python3 memory/memctl.py recall --peer c2c-3022464706 --top 8
python3 memory/memctl.py remember "内容" --peer c2c-3022464706 --kind fact --pin
python3 memory/memctl.py prune                      # 归档掉衰减到低强度的
```

- 每轮先 `ingest` + `digest`，然后读 `memory/digest.md`，成本很低。
- 聊天里临时冒出来的重要结论，用 `remember --pin` 手动补一条。
- 别记隐私：真实姓名、住址、电话、身份证、别人的聊天记录，不落盘。
